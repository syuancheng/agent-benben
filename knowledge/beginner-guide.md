# Tempo Fitness Beginner Guide

## Evidence Basis

Beginner guidance should reflect the 2026 American College of Sports Medicine position stand on resistance training prescription for healthy adults.

Reference links:

- PubMed: https://pubmed.ncbi.nlm.nih.gov/41843416/
- ACSM infographic: https://www.acsm.org/wp-content/uploads/2026/03/Resistance-Training-Position-Stand-infographic.pdf

Key principles for healthy adult beginners:

- The biggest improvement often comes from moving from no resistance training to some resistance training.
- A sustainable plan is better than a complicated plan the user will not follow.
- Healthy adults should train all major muscle groups at least 2 days per week and build gradually over time.
- Beginners do not need advanced methods such as training to momentary failure, complex periodization, or special equipment to make progress.
- For strength emphasis, heavier resistance can be useful when appropriate.
- For muscle growth, higher weekly volume is useful over time, but beginners should build toward this gradually.

This evidence applies to generally healthy adults. Users with pain, injury, pregnancy, high blood pressure, cardiovascular disease, recent surgery, medication concerns, or other medical conditions must follow the safety boundary and consult a qualified healthcare professional.

## First-Time Recommendation

For most beginners, the best starting point is:

1. Yoga, if the user wants a lower-intensity and more approachable first class.
2. Cycling, if the user wants structured cardio and is comfortable with moderate intensity.
3. HIIT only if the user already feels comfortable with high-intensity exercise.
4. Night run if the user already has basic running ability and no pain or injury.

If the user is unsure, recommend yoga or cycling first rather than HIIT.

If the user specifically wants strength, muscle gain, or better muscle function, explain that resistance training is important. Tempo's current class list includes cycling, yoga, HIIT, and night run; the user should contact staff to confirm whether a suitable resistance-training option, strength-focused session, or coaching recommendation is available.

## If The Goal Is Fat Loss

Recommend a combination of:

- HIIT for higher-intensity conditioning.
- Cycling for cardio training.
- Yoga for recovery, mobility, and consistency.
- Resistance training at least 2 days per week if the user's goal includes body composition, strength, or muscle maintenance.

Do not promise a specific amount of weight loss. Fat loss depends on training consistency, nutrition, recovery, and individual factors.

## If The Goal Is General Fitness

Recommend:

- Cycling for cardio.
- HIIT for conditioning.
- Yoga for mobility and recovery.
- Night run if the user wants running-based training.
- Resistance training at least 2 days per week to support muscular fitness and physical function.

Keep the beginner message simple: start with a routine the user can repeat consistently, then build gradually.

## If The Goal Is Strength Or Muscle Gain

Recommend adding resistance training as the foundation.

For healthy adult beginners:

- Start with 2 days per week.
- Cover all major muscle groups.
- Use manageable loads and good technique.
- Build gradually instead of jumping into high volume.
- Do not require advanced techniques at the beginning.

Tempo's current listed classes are cycling, yoga, HIIT, and night run. The assistant should not claim that a dedicated strength class exists unless staff confirms it. If the user wants strength or muscle gain, recommend contacting staff to confirm the best resistance-training option.

## If The Goal Is Better Running

Recommend night run if the user already has basic running readiness and no injury concerns.

Users with pain, injury, pregnancy, high blood pressure, cardiovascular disease, or other medical concerns must consult a doctor and inform the coach before class.

## Suggested Beginner Weekly Pattern

For a new user with no injury concerns:

- Start with 1-2 classes per week.
- Choose yoga or cycling first.
- Add HIIT after the user understands the studio format and feels comfortable with intensity.
- If strength, muscle gain, or body composition is a goal, add resistance training 2 days per week when a suitable option is confirmed by staff.
- Avoid daily high-intensity training at the beginning.

Example simple starting pattern:

- Week 1-2: 1 yoga or cycling class, plus 1 beginner-friendly resistance session if available.
- Week 3-4: 2-3 total sessions per week if recovery is good.
- Add HIIT only after the user feels comfortable with intensity and movement quality.

The assistant should not prescribe exact loads, sets, or intensities for a specific person. For individualized programming, recommend staff or a qualified coach.

## What To Expect In The First Class

Users should expect a coach-led class with warm-up, main training, and stretching.

First-time users should arrive early and tell the coach it is their first class.

## What To Tell The Coach

Users must proactively tell the coach before class if they:

- Are attending for the first time.
- Have any current discomfort.
- Have muscle soreness on the day.
- Have an old injury that has flared up.
- Have injury, high blood pressure, cardiovascular disease, pregnancy, or other medical concerns.
