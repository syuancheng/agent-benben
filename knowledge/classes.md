# Tempo Fitness Classes

## Class Types

Tempo Fitness currently offers:

- Cycling class
- Yoga class
- HIIT class
- Night run

## Class Duration

Each class is 45 to 60 minutes, including warm-up and stretching.

## Class Schedule

Weekday class windows:

- Morning: 06:45 / 07:30
- Lunch: 12:15 / 13:00
- Evening: 18:15 / 19:15 / 20:15

Weekend class windows:

- Morning and afternoon classes between 08:30 and 16:00

Specific weekly schedules and available slots should be confirmed with staff.

## Cycling Class

Cycling class is a cardio-focused indoor cycling session.

Best for users who want:

- Cardiovascular training.
- A structured, high-energy group class.
- Lower-impact conditioning compared with running.

Users with knee pain, cardiovascular concerns, pregnancy, high blood pressure, or other medical issues should consult a doctor and inform the coach before class.

## Yoga Class

Yoga class focuses on mobility, flexibility, breathing, and body control.

Best for users who want:

- Lower-intensity training.
- Mobility and flexibility.
- Recovery support between harder sessions.
- A beginner-friendly starting point.

Yoga is not a substitute for medical rehabilitation.

## HIIT Class

HIIT is a high-intensity interval training class.

Best for users who want:

- High-intensity conditioning.
- Fat-loss support.
- Better general fitness.
- A challenging workout.

HIIT may not be the best first class for users who are very new to exercise, injured, pregnant, returning from illness, or unsure about their current fitness.

## Night Run

Night run is a running-focused group session.

Best for users who want:

- Running consistency.
- Cardiovascular fitness.
- A social running environment.
- Support for general running goals.

Users with running-related pain or injury should not rely on the assistant for clearance. They should consult a healthcare professional and inform staff before joining.

## Intensity Guide

- Yoga: low to moderate intensity.
- Cycling: moderate to high intensity.
- HIIT: high intensity.
- Night run: moderate to high intensity depending on route, pace, and session plan.

## Equipment

Users should bring comfortable workout clothes, appropriate training shoes, and water.

For cycling, users should confirm with staff whether special cycling shoes are required or provided.
